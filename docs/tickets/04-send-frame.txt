TICKET 04 — SEND A FRAME BACK (UNMASKED) — THE ECHO MILESTONE
================================================================================
PHASE: MVP
DEPENDS ON: 03

GOAL
  Build and write an outbound text frame; echo back whatever the client sends.
  FIRST GENUINE "IT WORKS" MOMENT.

WHAT TO DO
  - Byte 0 = 0x81 (FIN=1, opcode=0x1 text)
  - Byte 1 = payload length with MASK bit = 0, using the same
    0-125 / 126+2bytes / 127+8bytes rules as inbound.
  - Then the raw UTF-8 payload.
  - Server->client frames must NOT be masked.

CONCEPTS THIS TEACHES
  - Frame serialization; choosing the length encoding
  - The masking asymmetry (client masks; server does not)

GOTCHAS
  - Setting the MASK bit on a server frame => browser drops the connection.
  - Build the whole frame in a buffer, write it, flush.
  - Get the 125 / 126 / 127 length boundaries exactly right.

DEFINITION OF DONE
  - Browser: ws.send("hi") -> ws.onmessage receives "hi" back. Round trip on
    code you wrote byte-by-byte.
