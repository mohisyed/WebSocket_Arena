TICKET B2 — CLIENT-SIDE PREDICTION + SERVER RECONCILIATION
================================================================================
PHASE: B
DEPENDS ON: B1

GOAL
  Make YOUR dot respond instantly (no round-trip delay) while the server stays
  authoritative.

WHAT TO DO
  - Client-side prediction: the client applies its own input immediately.
  - Server reconciliation: server is authoritative; the client replays its
    unacknowledged inputs on top of each authoritative snapshot to correct drift.
  - (Read about lag compensation / server-side rewind — likely OPTIONAL for a
    non-combat dot arena.)

CONCEPTS / GOTCHAS
  - Prediction needs deterministic movement + per-input SEQUENCE NUMBERS so the
    client knows which inputs the server has applied.
  - Reconciliation re-simulates pending inputs every correction — keep movement
    logic IDENTICAL on client and server.

DEFINITION OF DONE
  - Your dot responds instantly to keypresses, yet snaps correctly to server
    authority under induced latency.
  - You can explain prediction vs reconciliation vs interpolation out loud.
